# 스파이더맨 3D 프로토타입

Unity 6.6용 3D 프로토타입입니다. 프로젝트 버전은 Unity 6000.6.5f1로 지정했습니다. 높이가 다른 직육면체 건물 두 개 사이에서 이동, 벽 타기, 번갈아 쓰는 양손 거미줄, 진자 운동, 짧은 고속 당기기, 시점 전환을 시험할 수 있습니다. 캐릭터는 사람에 가까운 머리·몸통·팔다리 비율에 붉은 마스크와 흰 렌즈, 거미 문양, 푸른 하의와 붉은 부츠를 더한 간단한 스파이더맨 스타일입니다. 1인칭에는 구형 손 대신 손목에서 손바닥으로 이어지는 전용 메시와 세 마디로 움직이는 손가락, 길이에 따라 굵기가 달라지는 팔이 보입니다. 기본 자세는 두 손의 손바닥을 이전과 반대로 아래쪽으로 향하게 하고 손가락은 편 상태입니다. 발사할 때 손바닥을 180도 뒤집되 손가락은 위로 향하게 하고 중지와 약지를 접습니다. 세게 당길 때는 사진의 주먹을 시계방향으로 90도 돌린 듯 손가락 마디가 세로로 보이게 쥐고, 흰 줄은 세로로 유지합니다. 손의 검은 문양은 제거했습니다. 벽에서는 양손을 번갈아 뻗어 붙잡고, 카메라와 손·팔을 벽 표면 앞에 두도록 보정합니다. 카메라는 넓은 시야각으로 설정했습니다.

## 열기

1. Unity Hub에서 **Unity 6.6** 에디터를 설치합니다. 설치한 6.6의 세부 버전이 6000.6.5f1과 다르면 Hub에서 설치된 6.6 버전을 선택해 열면 됩니다.
2. Hub의 **Projects → Add → Add project from disk**에서 `D:\스파이더맨` 폴더를 선택합니다.
3. 프로젝트를 처음 열면 장면과 재질이 자동으로 생성되고 `SpiderPlayground` 장면이 열립니다. Hierarchy 위에 `SpiderPlayground`가 보이면 **Play**를 누릅니다.
4. 빈 `Untitled` 장면이 보이면 먼저 **Play**를 끈 뒤 Unity 상단 메뉴 **Spider Game → Open Demo Scene**을 누릅니다. `Assets/Scenes/SpiderPlayground.unity`를 더블클릭해도 됩니다.
5. 데모 장면을 새로 생성해야 할 때만 **Spider Game → Rebuild Demo Scene**을 누릅니다. 이 메뉴는 기존 데모 장면을 덮어쓰므로 장면을 직접 수정한 뒤에는 사용하지 마세요.

게임 입력에는 Unity의 기본 **Input Manager (Old)**를 사용합니다. 입력 관련 경고가 표시되면 **Edit → Project Settings → Player → Other Settings → Active Input Handling**을 **Both** 또는 **Input Manager (Old)**로 설정하세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 바라보는 방향 변경 |
| W/A/S/D | 바닥 및 공중 이동·방향 조절. 점프 직후에는 바닥 이동 속도가 이어지지 않습니다. 벽에 붙은 상태에서는 W로 오르고 S로 내려가며 A/D로 옆으로 이동 |
| Space | 바닥에서 점프, 벽을 타는 중에는 벽에서 떨어지기 |
| 좌클릭 | 발사 → 다시 누르면 줄 놓기 → 다시 누르면 반대 손으로 발사 |
| 우클릭 | 걸린 거미줄을 한 번 세게 당겨 짧은 고속 직선 이동 후 줄을 놓기. 벽 타기 중 다른 벽에 줄을 걸었다면 현재 벽에서 떨어지며 당기기 |
| V | 1인칭 / 3인칭 전환 |
| R | 시작 위치로 복귀 |
| Esc | 마우스 잠금 해제 (다시 클릭하면 잠금) |

화면 중앙의 `+`로 건물 표면을 조준하세요. 흰색 거미줄은 이전보다 2배 빠르게 손에서 날아가며, 허공을 향해 발사하면 끝까지 날아갔다가 사라집니다. 손에서 목표까지 다른 건물이 가로막으면 먼저 닿는 표면에 맞고, 매달린 줄이 건물에 가로막히면 즉시 끊어져 건물을 통과해 그려지지 않습니다. 건물에 걸리면 충돌 표면에 고정되며 일정한 줄 길이로 중력이 작용하는 진자운동을 시작합니다. 진자운동 중 A/D는 줄에 수직인 방향으로 빠르게 가속하며, 처음 누르거나 방향을 바꿀 때 짧은 추진력이 더해집니다. 스윙 속도는 움직이는 방향으로 점차 빨라지되 최고 속도에서 멈춥니다. **우클릭**하면 한 손으로 줄을 세게 당겨 최대 0.32초·12m 동안 고속으로 직진합니다. 벽 약 2m 앞에서 이동을 멈추도록 제한하며, 직진이 끝나면 줄이 즉시 사라지고 중력이 다시 작용합니다. 공중에서 건물 옆면에 닿으면 거미줄 사용 여부와 관계없이 벽 타기 상태로 바뀝니다. 좌클릭으로 직접 놓은 줄은 짧게 흐려진 뒤 삭제됩니다.

바닥에서는 건물 벽을 바라보며 가까이 가서 **W**를 누르면 매달립니다. 공중에서는 자유낙하·점프·거미줄 이동 중 건물 옆면에 닿으면 자동으로 매달립니다. W를 놓으면 그 자리에 붙어 있습니다. 벽 중간에서 **Space**를 누르면 벽에서 떨어집니다. 벽에 붙은 채 다른 건물 벽이나 같은 건물의 다른 면에 거미줄을 건 뒤 **우클릭**하면 현재 벽에서 떨어져 그쪽으로 당겨지며, 도착한 벽에 닿으면 다시 벽 타기 상태가 됩니다. 옥상 가장자리에서는 상승이 멈추며, 이때 **Space**를 누르면 점프 자세로 몸을 들어 올린 다음 옥상 안쪽으로 넘어갑니다. 팔다리 애니메이션은 Play 중 기존 캐릭터에 자동으로 적용되므로 장면을 다시 생성할 필요가 없습니다.

옥상은 건물 자체의 윗면에 얇은 시각용 표면을 올렸습니다. 시각용 표면에는 충돌체가 없어 벽 타기를 막는 턱이 생기지 않으며, 겹친 두 면 때문에 빛이 흔들리는 현상도 피합니다.

## 나중에 건물 교체하기

기본 장면의 `Central Block - Replace with Building Later`와 `Second Block - Replace with Building Later` 오브젝트를 원하는 건물 에셋으로 교체하면 됩니다. 새 건물에는 충돌체와 `WebAttachSurface` 컴포넌트를 추가하세요. 거미줄은 이 컴포넌트가 있는 오브젝트의 충돌체에 걸립니다.

주요 코드: `Assets/Scripts/SpiderController.cs`(조작, 벽 타기 및 거미줄), `Assets/Scripts/SpiderProceduralAnimator.cs`(3인칭 팔다리 동작), `Assets/Scripts/SpiderFirstPersonHands.cs`(1인칭 손·팔 동작), `Assets/Editor/SpiderSceneBuilder.cs`(데모 장면 생성).
